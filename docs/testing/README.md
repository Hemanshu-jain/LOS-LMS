# Manual testing

Logins and a script of sample data for hands-on testing of a running system (separate from the automated tests, which
run with `dotnet test tests/LosLms.Tests`).

| File | For |
|---|---|
| `TEST-DATA-1-ADMIN-Rajesh-Deshmukh.md` | Testing as a company **Admin** |
| `TEST-DATA-2-STAFF-Imran-Shaikh.md` | Testing as **Staff** |

These files contain only made-up people and example addresses. Never put real customer data or real credentials in them.
