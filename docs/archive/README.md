# Archive

Historical material from the original build. **It is kept for reference and may not match the current screens or
behaviour.** For how the system works today, use [`../development/ARCHITECTURE.md`](../development/ARCHITECTURE.md) and
the operations guides.

| Item | What it is |
|---|---|
| `wireframes/` | The original React reference specs, one per screen, and the nine-screen flow archive the first build was made from |
| `WALKTHROUGH-STAGES-1-TO-5.md` | The first end-to-end walkthrough (an early sample application) |
| `DEMO-WALKTHROUGH-APPLICATION-LN-2026-004900.md` | Demo 1: a commercial-vehicle loan with three parties; exercises the RCU override gate |
| `DEMO-WALKTHROUGH-APPLICATION-LN-2026-004901.md` | Demo 2: a loan against property with one party; exercises the eligibility deviation approver note |

Both demo walkthroughs are step-by-step scripts that create a brand-new application by hand and take it from creation to
disbursement. They were written against the first build, so screen details have since changed.
