Connect to LMS

API reference Connect guide

Read this first: widen the APIKEY column

Do this before anything else. The saved connection is about 600 to 900 characters long. If your APIKEY column is short, saving fails with "String or binary data would be truncated ... column APIKEY" and the customer sees "Connected" but is not. Run this once on the database: 
ALTER TABLE dbo.APIKEY ALTER COLUMN APIKEY NVARCHAR(MAX) NULL;

Your customer clicks one button in your software, types a short code into LMS, and clicks Allow. From then on your software sends loans to LMS for that company on its own. Nobody copies or pastes an API key.

(For the curious: this is the standard OAuth 2.0 device authorization, RFC 8628. It is what smart TVs and the GitHub command line use. You do not need any library: the code below is complete.)

What your customer sees

  1. In your software they click Connect to LMS. A short code such as WDJB-MJHT appears and their browser opens LMS.
  2. They sign in to LMS. Only the company owner or a manager can approve; staff are asked to get one.
  3. They check that the code on the LMS page is the code on your screen, and see your software's name and what it will be allowed to do.
  4. They click Allow. Your screen says Connected to LMS within a few seconds.

Words used here

WordWhat it means
Client IDYour software's name tag at LMS. It is not a secret, so you can put it in your code. Desktop software gets no secret, because anything shipped inside an .exe can be read.
Device codeA long random value LMS gives your software when the customer clicks Connect. Your software keeps it and uses it to ask "have they approved yet?". Never show it.
User codeThe short code your software shows on screen (WDJB-MJHT). The customer sees it in LMS too, so they can check it is the same.
Access tokenA pass you send with every data call instead of an API key. It works for about 1 hour.
Refresh tokenGets a new access token when the old one runs out. Each refresh token works once, and you get a new one every time.

What you get from us

  • Your client ID. We register your software as a desktop app, so there is no secret. The code below shows LC_PUT_YOUR_CLIENT_ID_HERE as a placeholder: replace it with the real one.
  • The scopes to ask for: loans:write loans:read.
Copy and paste the client ID, never retype it. The ID is one unbroken string. A single extra _ or - gives invalid_client.

All addresses start with https://los-lms.bhodhix.com. In your TableApiKey table, add a row named LMS (once), with ApiURL = https://los-lms.bhodhix.com/api/v1/loans. The data calls are in the API reference.

1. Add the module

Add a new file LmsConnect.vb to the project and paste this in. Put your client ID on the LmsClientId line. It uses only things you already have: HttpClient and System.Text.Json.

Imports System.Net
Imports System.Net.Http
Imports System.Security.Cryptography
Imports System.Text
Imports System.Text.Json
Imports System.Threading

' Connect to LMS: links this install to one finance company's LOS/LMS workspace.
Public Module LmsConnect
    Public Const LmsBase As String = "https://los-lms.bhodhix.com"
    Public Const LmsClientId As String = "LC_PUT_YOUR_CLIENT_ID_HERE"
    Private Const DeviceGrant As String = "urn:ietf:params:oauth:grant-type:device_code"

    Private ReadOnly Http As New HttpClient() With {.Timeout = TimeSpan.FromSeconds(30)}
    Private ReadOnly Json As New JsonSerializerOptions With {.PropertyNameCaseInsensitive = True}
    Private ReadOnly RefreshLock As New SemaphoreSlim(1, 1)

    ' What LMS answers when Connect is clicked.
    Public Class DeviceStart
        Public Property device_code As String
        Public Property user_code As String
        Public Property verification_uri As String
        Public Property verification_uri_complete As String
        Public Property expires_in As Integer
        Public Property interval As Integer
    End Class

    ' What /oauth/token answers: tokens, or an error name.
    Public Class TokenReply
        Public Property access_token As String
        Public Property refresh_token As String
        Public Property expires_in As Integer
        Public Property [error] As String
        Public Property error_description As String
    End Class

    ' The customer has to click Connect to LMS again.
    Public Class LmsNotConnectedException
        Inherits Exception
        Public Sub New()
            MyBase.New("This software is not connected to LMS. Open API settings and click Connect to LMS.")
        End Sub
    End Class

    Private Async Function PostFormAsync(path As String, fields As Dictionary(Of String, String),
                                         Optional cancel As CancellationToken = Nothing) As Task(Of (Ok As Boolean, Status As HttpStatusCode, Reply As TokenReply, Raw As String))
        Using form As New FormUrlEncodedContent(fields)
            Using response = Await Http.PostAsync(LmsBase & path, form, cancel)
                Dim raw = Await response.Content.ReadAsStringAsync()
                Dim reply As TokenReply = Nothing
                Try
                    reply = JsonSerializer.Deserialize(Of TokenReply)(raw, Json)
                Catch
                    reply = New TokenReply()
                End Try
                Return (response.IsSuccessStatusCode, response.StatusCode, reply, raw)
            End Using
        End Using
    End Function

    ' (steps 2 to 6 below add the rest of this module)
End Module

2. Save the tokens in your TableApiKey row

Keep the token values as a small piece of JSON in the ApiKey field of the LMS row, encrypted with Windows DPAPI (built into Windows; the text can only be read back by the same Windows user on the same PC). No new columns are needed, but the APIKEY column must be wide enough: see the box at the top of this page.

Add the NuGet package System.Security.Cryptography.ProtectedData to the project, then add this inside the module. Change only the line that saves the row (TableApiKey.Update) to the save you already use on ApiKeySetting.vb.

    Public Class LmsTokens
        Public Property AccessToken As String
        Public Property RefreshToken As String
        Public Property ExpiresUtc As DateTime
    End Class

    Private Const Encrypted As String = "dpapi:"

    ' Nothing = not connected.
    Public Function LoadLmsTokens() As LmsTokens
        Dim row = TableApiKey.GetByName("LMS")
        If row Is Nothing OrElse Not row.IsActive OrElse String.IsNullOrWhiteSpace(row.ApiKey) Then Return Nothing
        If Not row.ApiKey.StartsWith(Encrypted) Then Return Nothing
        Try
            Dim clear = ProtectedData.Unprotect(Convert.FromBase64String(row.ApiKey.Substring(Encrypted.Length)), Nothing, DataProtectionScope.CurrentUser)
            Return JsonSerializer.Deserialize(Of LmsTokens)(Encoding.UTF8.GetString(clear), Json)
        Catch ex As CryptographicException
            Return Nothing   ' saved by another Windows user or another PC: connect again here
        End Try
    End Function

    ' Save new tokens (encrypted), or pass Nothing to mark this install as not connected.
    Public Sub SaveLmsTokens(tokens As LmsTokens)
        Dim row = TableApiKey.GetByName("LMS")
        If tokens Is Nothing Then
            row.ApiKey = ""
        Else
            Dim secret = ProtectedData.Protect(Encoding.UTF8.GetBytes(JsonSerializer.Serialize(tokens)), Nothing, DataProtectionScope.CurrentUser)
            row.ApiKey = Encrypted & Convert.ToBase64String(secret)
        End If
        row.IsActive = tokens IsNot Nothing
        TableApiKey.Update(row)   ' use the same save method you use on ApiKeySetting today
    End Sub

    Public ReadOnly Property IsLmsConnected As Boolean
        Get
            Return LoadLmsTokens() IsNot Nothing
        End Get
    End Property

    Public Function ToTokens(reply As TokenReply) As LmsTokens
        Return New LmsTokens With {
            .AccessToken = reply.access_token,
            .RefreshToken = reply.refresh_token,
            .ExpiresUtc = DateTime.UtcNow.AddSeconds(reply.expires_in)
        }
    End Function

3. The "Connect to LMS" button

First add these two functions to the module. The first asks LMS for a code. The second waits while the customer approves in the browser, asking LMS every few seconds (this repeated asking is called "polling").

    ' Ask LMS for a code to show the customer.
    Public Async Function StartConnectAsync() As Task(Of DeviceStart)
        Using form As New FormUrlEncodedContent(New Dictionary(Of String, String) From {
                {"client_id", LmsClientId}, {"scope", "loans:write loans:read"}})
            Using response = Await Http.PostAsync(LmsBase & "/oauth/device_authorization", form)
                Dim raw = Await response.Content.ReadAsStringAsync()
                If Not response.IsSuccessStatusCode Then Throw New Exception("LMS said: " & raw)
                Return JsonSerializer.Deserialize(Of DeviceStart)(raw, Json)
            End Using
        End Using
    End Function

    ' Wait until the customer clicks Allow or Deny. Returns the tokens, or Nothing if they
    ' clicked Deny or the code ran out (15 minutes).
    Public Async Function WaitForApprovalAsync(start As DeviceStart, cancel As CancellationToken) As Task(Of TokenReply)
        Dim waitSeconds = Math.Max(start.interval, 5)
        Dim giveUpAt = DateTime.UtcNow.AddSeconds(start.expires_in)
        While DateTime.UtcNow < giveUpAt
            Await Task.Delay(waitSeconds * 1000, cancel)
            Dim result = Await PostFormAsync("/oauth/token", New Dictionary(Of String, String) From {
                {"grant_type", DeviceGrant}, {"device_code", start.device_code}, {"client_id", LmsClientId}}, cancel)
            If result.Ok Then Return result.Reply
            Select Case result.Reply?.error
                Case "authorization_pending"
                    ' Not yet: the customer is still signing in. Keep waiting.
                Case "slow_down"
                    waitSeconds += 5   ' LMS asks us to ask less often
                Case Else
                    Return Nothing     ' access_denied, expired_token, or anything else: stop
            End Select
        End While
        Return Nothing
    End Function

Then, on ApiKeySetting.vb, add a button btnConnectLms, a large label lblLmsCode (about 28pt, monospace) and a label lblLmsStatus:

    Private connectCancel As CancellationTokenSource

    Private Async Sub btnConnectLms_Click(sender As Object, e As EventArgs) Handles btnConnectLms.Click
        btnConnectLms.Enabled = False
        connectCancel = New CancellationTokenSource()
        Try
            Dim start = Await LmsConnect.StartConnectAsync()
            lblLmsCode.Text = start.user_code
            lblLmsStatus.Text = "Your browser has opened LMS. Sign in, check this code matches, and click Allow."
            ' The system browser, not WebView2: the customer's own browser keeps their LMS login.
            Process.Start(New ProcessStartInfo(start.verification_uri_complete) With {.UseShellExecute = True})

            Dim reply = Await LmsConnect.WaitForApprovalAsync(start, connectCancel.Token)
            If reply Is Nothing Then
                lblLmsStatus.Text = "Not connected (declined, or the code ran out). Click Connect to try again."
            Else
                LmsConnect.SaveLmsTokens(LmsConnect.ToTokens(reply))
                lblLmsStatus.Text = "Connected to LMS."
            End If
        Catch ex As OperationCanceledException
            lblLmsStatus.Text = "Cancelled."
        Catch ex As Exception
            lblLmsStatus.Text = "Could not connect: " & ex.Message
        Finally
            lblLmsCode.Text = ""
            btnConnectLms.Enabled = True
        End Try
    End Sub

    ' If the screen closes while waiting, stop asking LMS.
    Private Sub ApiKeySetting_FormClosing(sender As Object, e As FormClosingEventArgs) Handles MyBase.FormClosing
        connectCancel?.Cancel()
    End Sub

4. GetLmsTokenAsync: always a working access token

Your data functions call this instead of reading ApiClass.ApiKey. It returns the saved access token while it is fresh, and gets a new one when it is about to run out. If LMS says the connection is gone, it marks the install "not connected" and throws LmsNotConnectedException, so you can tell the user to click Connect again.

    ' A working access token for LMS. forceRefresh:=True after a 401 reply.
    Public Async Function GetLmsTokenAsync(Optional forceRefresh As Boolean = False) As Task(Of String)
        ' One refresh at a time: a refresh token works only once.
        Await RefreshLock.WaitAsync()
        Try
            Dim saved = LoadLmsTokens()
            If saved Is Nothing Then Throw New LmsNotConnectedException()
            If Not forceRefresh AndAlso DateTime.UtcNow < saved.ExpiresUtc.AddMinutes(-1) Then Return saved.AccessToken

            Dim result = Await PostFormAsync("/oauth/token", New Dictionary(Of String, String) From {
                {"grant_type", "refresh_token"}, {"refresh_token", saved.RefreshToken}, {"client_id", LmsClientId}})
            If result.Ok Then
                Dim fresh = ToTokens(result.Reply)
                SaveLmsTokens(fresh)   ' save the NEW refresh token every time
                Return fresh.AccessToken
            End If
            If result.Status = HttpStatusCode.BadRequest OrElse result.Status = HttpStatusCode.Unauthorized Then
                SaveLmsTokens(Nothing)  ' disconnected in LMS, or the refresh token was refused
                Throw New LmsNotConnectedException()
            End If
            Throw New Exception("LMS is not reachable right now. Try again in a minute.")   ' keep the tokens
        Finally
            RefreshLock.Release()
        End Try
    End Function

5. Change your data functions

Wherever a function sends a request to LMS, it sets the Authorization header from the API key. Change only that value. The address, the body and how you read the reply stay as the API reference describes:

- request.Headers.Authorization = New AuthenticationHeaderValue("Bearer", ApiClass.ApiKey)
+ request.Headers.Authorization = New AuthenticationHeaderValue("Bearer", Await GetLmsTokenAsync())

(If you set it on client.DefaultRequestHeaders.Authorization instead, change it there in the same way.)

So that a connection cut in LMS is noticed straight away, retry once on a 401 with a forced refresh:

Dim response = Await client.SendAsync(request)
If response.StatusCode = HttpStatusCode.Unauthorized Then
    ' Expired early or cut in LMS: refresh once and try again.
    Using retry = New HttpRequestMessage(request.Method, request.RequestUri)
        retry.Content = request.Content   ' the same body (rebuild it if you already read it)
        retry.Headers.Authorization = New AuthenticationHeaderValue("Bearer", Await GetLmsTokenAsync(forceRefresh:=True))
        response = Await client.SendAsync(retry)
    End Using
End If

Wrap the call where your screens use these functions:

Try
    Await UpsertLoansAsync(loans)
Catch ex As LmsConnect.LmsNotConnectedException
    MessageBox.Show(ex.Message, "LMS")   ' "...click Connect to LMS"
End Try

6. The "Disconnect" button

    ' In the module: tell LMS, then forget the tokens on this PC.
    Public Async Function DisconnectLmsAsync() As Task
        Dim saved = LoadLmsTokens()
        If saved IsNot Nothing Then
            Try
                Await PostFormAsync("/oauth/revoke", New Dictionary(Of String, String) From {
                    {"token", saved.RefreshToken}, {"client_id", LmsClientId}})
            Catch
                ' Offline: still disconnect here. The owner can also remove it in LMS under Connected apps.
            End Try
        End If
        SaveLmsTokens(Nothing)
    End Function
    ' On ApiKeySetting.vb
    Private Async Sub btnDisconnectLms_Click(sender As Object, e As EventArgs) Handles btnDisconnectLms.Click
        Await LmsConnect.DisconnectLmsAsync()
        lblLmsStatus.Text = "Disconnected from LMS."
    End Sub

LMS always answers 200 here, even if the token was already gone. Loans already sent stay in LMS.

One install = one company. Connect links the install to the company whose owner or manager clicked Allow. To switch company: Disconnect, then Connect while signed in to the other company.

The HTTP calls (no VB)

For checking with a tool like Postman or curl. The three /oauth calls are form posts (Content-Type: application/x-www-form-urlencoded), not JSON.

curl -X POST https://los-lms.bhodhix.com/oauth/device_authorization \
  -d client_id=LC_PUT_YOUR_CLIENT_ID_HERE -d "scope=loans:write loans:read"

{ "device_code": "...", "user_code": "WDJB-MJHT",
  "verification_uri": "https://los-lms.bhodhix.com/link",
  "verification_uri_complete": "https://los-lms.bhodhix.com/link?code=WDJB-MJHT",
  "expires_in": 900, "interval": 5 }
# while waiting (every "interval" seconds)
curl -X POST https://los-lms.bhodhix.com/oauth/token \
  -d grant_type=urn:ietf:params:oauth:grant-type:device_code \
  -d device_code=... -d client_id=LC_PUT_YOUR_CLIENT_ID_HERE
#   400 {"error":"authorization_pending"}   -> wait and ask again
#   400 {"error":"slow_down"}               -> add 5 seconds to your wait
#   400 {"error":"access_denied"} / {"error":"expired_token"} -> stop
#   200 {"access_token":"...","token_type":"Bearer","expires_in":3599,"refresh_token":"...","scope":"loans:write loans:read"}

# refresh (save the NEW refresh token)
curl -X POST https://los-lms.bhodhix.com/oauth/token \
  -d grant_type=refresh_token -d refresh_token=... -d client_id=LC_PUT_YOUR_CLIENT_ID_HERE
curl -X POST https://los-lms.bhodhix.com/oauth/revoke -d token=... -d client_id=LC_PUT_YOUR_CLIENT_ID_HERE

# then call the data API with the access token
curl https://los-lms.bhodhix.com/api/v1/loans/PV-000123 -H "Authorization: Bearer ..."

When things go wrong

"String or binary data would be truncated ... column APIKEY" when savingThe APIKEY column is too short for the encrypted tokens (about 600 to 900 characters).Run ALTER TABLE dbo.APIKEY ALTER COLUMN APIKEY NVARCHAR(MAX) NULL; once, then click Connect again.
invalid_client when clicking ConnectThe client ID in the module is wrong: still the placeholder, retyped with a typo, or not registered as a desktop app.Copy and paste the ID again. Ask us if it still fails.

LMS page: "That code is wrong or has expired"A typo, or more than 15 minutes passed.Click Connect again for a fresh code. After 5 wrong codes LMS pauses for 15 minutes.

Test before going live

  • Use your own company's LMS login. Click Connect, sign in with it in the browser, check the code matches, and click Allow. Your screen should say Connected within a few seconds.
  • Push one test loan, then check it with the Check call. It appears in your company in LMS.
  • Set ExpiresUtc in the saved JSON to a time in the past, then push again. It should refresh silently and work.
  • In LMS, open Connected apps and click Disconnect. Your next call should show "click Connect to LMS".
  • Click Connect, then Deny in the browser. Your screen should show "Not connected".
  • Click your Disconnect button. Connected apps in LMS no longer lists your software.

Questions? Contact the LMS team. We are happy to look at your test calls with you.
